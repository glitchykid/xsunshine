# v0.3.2 - Reliable summaries when output fails

## Changes

- Preserve partial totals on standard error when standard output stops working; fallback output remains plain even with forced colors.
- Attempt the final JSONL summary independently of terminal output, including when both terminal streams fail.
- Report corrected totals marked `failed` if the final trace write fails after the terminal total was printed.
- Handle closed output pipes without Python shutdown exceptions or an unexpected exit code of 120. Cleanup stops and exits with code 1.

## Validation

All 68 automated tests pass on Windows, including the PowerShell launcher and isolated registry integration tests. Seven new regression tests cover persistent write failures, flush failures, unavailable terminal streams, retained counts after deletion, and actual closed pipes through both Python launchers. Ruff lint and formatting checks pass. The wheel is built and tested with isolated filesystem and registry fixtures.

## Limitations

A failed trace may be incomplete. If all output destinations are unavailable, totals cannot be delivered. Completed deletions remain applied after a reporting failure. Preview remains the default; Python is required. See the [README](https://github.com/glitchykid/xsunshine#readme) for setup and cleanup rules.
