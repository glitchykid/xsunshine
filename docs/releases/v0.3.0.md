# v0.3.0 — Live colors and final totals

- Color-coded live statuses: cyan candidates, green deletions, yellow skips, and red errors.
- Automatic Windows console color support, with `--color auto|always|never`, `NO_COLOR`, plain redirected output, and restoration of the original console mode.
- Final directory and registry-view breakdowns followed by a combined `TOTAL` line.
- Partial totals survive interruption within a scope; completed deletions remain reflected in the report.
- JSONL summaries include `status` and `by_kind`, with no terminal escape sequences.

## Usage

```powershell
python -m xsunshine --all
python -m xsunshine --all --apply --color always
```

Colors are enabled automatically in supported terminals. Preview is still the default. Counts are summed across scopes and registry views; shared registry branches may appear in both view previews.

## Validation

All 52 automated tests pass, covering combined and zero totals, interrupted progress, color policy and fallback, plain trace logs, existing cleanup behavior, and the PowerShell launcher. Ruff checks, wheel packaging, and an installed-package cleanup smoke test validate the release. Destructive checks use isolated fixtures only.

The wheel requires Python 3.15 or newer. The source archive also includes the optional PowerShell launcher. All existing scope, permission, and link-handling limitations remain documented in the [README](https://github.com/glitchykid/xsunshine#readme).
