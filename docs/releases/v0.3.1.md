# v0.3.1 — Reliability and Windows usability

## Changes

- Accept absolute registry scopes such as `HKCU:\Software` and `Registry::HKEY_CURRENT_USER\Software`, including trailing backslashes. Equivalent spellings are normalized before scope deduplication.
- Handle valid literal registry names such as `.` and `..` without aborting a scan or treating them as parent-directory references. Spaces, brackets, and forward slashes remain part of key names.
- Continue inspecting neighboring entries when a file disappears during directory enumeration. Final emptiness checks and non-recursive deletion remain in place.
- Stop cleanup immediately when progress reporting fails, instead of treating a trace or terminal write failure as a per-object access error. Preserve completed counts and report a failed run when output remains available.

## Validation

All 61 automated tests pass. Regression tests reproduce the earlier failures and cover path aliases, literal registry keys, scope boundaries, disappearing entries, trace-write failures, and retained deletion counts. Existing filesystem, registry, terminal-color, and PowerShell-launcher tests remain part of validation. Packaging and an installed-package smoke test use isolated fixtures only.

## Usage

```powershell
python -m xsunshine --registry 'HKCU:\Software' --registry-view both
```

Preview remains the default; add `--apply` to perform cleanup. Python is required. Existing permission, scope, and link-handling rules remain unchanged; see the [README](https://github.com/glitchykid/xsunshine#readme).
