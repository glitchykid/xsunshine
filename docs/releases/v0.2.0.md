# v0.2.0 — Windows terminal cleanup

The first runnable application milestone recursively cleans empty directories and registry keys from the terminal. It uses Python 3.15.1 with an optional PowerShell 7.6 launcher and no third-party runtime dependencies.

## Added

- Explicit directory and registry scopes, plus `--all` for fixed local volumes and loaded machine/user registry hives.
- Both 32-bit and 64-bit registry views, recursive post-order traversal, and same-pass removal of newly empty parents.
- Preview by default and `--apply` for deletion. Files and registry values, including empty-valued entries, are preserved.
- Scope boundaries, link detection, per-object error reporting, and transactional registry deletion with rollback.
- Compact terminal output, exit codes, optional JSONL diagnostics, and a PowerShell launcher.
- Contributor instructions recording terminal requirements and tracer-bullet development from *The Pragmatic Programmer*.

## Validation

- 41 automated tests on Windows with Python 3.15.1, including real isolated registry and filesystem operations, transaction failure, concurrent writes, links, and PowerShell launching.
- Ruff lint and formatting checks, Markdown link checks, and Git whitespace checks.
- Python wheel build and installed-package smoke checks.
- System-wide deletion was not executed; destructive testing was confined to generated fixtures.

## Usage

Download the wheel from this release's assets and install it with Python:

```powershell
python -m pip install .\xsunshine-0.2.0-py3-none-any.whl
```

The wheel installs the Python command; the optional PowerShell launcher is included in the source archive.

```powershell
python -m xsunshine --all
python -m xsunshine --all --apply
```

See the [README](https://github.com/glitchykid/xsunshine#readme) for setup, scoped commands, and cleanup rules.

## Limitations

Python is required; this release is not a standalone executable. Offline registry hives are not loaded, and filesystem/registry links are skipped. Permission failures and unavailable transactions are reported; the application does not take ownership or bypass ACLs. Shared registry branches may appear in both view previews. Preview results can change, and moving scanned trees concurrently is unsupported. Empty keys and directories may still be required by installed software; deletions are permanent and logs are not backups.
